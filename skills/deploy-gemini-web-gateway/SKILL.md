# 部署 Gemini 网页会话网关

将用户自有、已获授权的 Gemini 网页会话接入专用网关，完成最小网络暴露、真实模型发现和所选 GUI 配置。保持现有服务、默认模型、聊天历史与共享网络不变，除非用户明确要求修改。

## 选择工作路径

- 新部署/升级 NAS 网关：读 [references/nas-gateway.md](references/nas-gateway.md)。
- 部署到 Mac 本机：读 [references/mac-local.md](references/mac-local.md)，根据现有容器运行时或无容器偏好选择路径；默认只绑定loopback，不去修改NAS。
- 网关已存在，只新增或迁移 GUI：先只读确认地址、认证和模型目录，再读 [references/gui-clients.md](references/gui-clients.md)；不要重新部署 NAS。
- 登录态、模型不全、拒答或流式异常：读 [references/validation-and-diagnosis.md](references/validation-and-diagnosis.md)。
- Agent 声称不能读本地文件、工具参数 502、带工具流式等待或文件产物验收：读 [references/file-tools-and-agents.md](references/file-tools-and-agents.md)。仅切模型或打开能力开关不能代替执行器与网关适配。

本 skill 提供方法与空 key 模板，不分发增强网关的一键安装器或现场补丁。实现增强路径前，先核对所选源码/SDK 的接口、实际加载入口及对应适配代码；Mac 同适配未实机验收，不照搬 NAS 结论。

## 先做决定，再操作

1. 核实部署位置（NAS/服务器还是Mac本机）、进程/容器/目录归属、客户端版本和用户希望保留的配置；只读查看 CPU、内存、架构、运行时、端口、存储及适用的 cgroup 能力。不要从旧快照推断当前状态。
2. 明确网关地址、配置方式、备份/回滚点及修改范围。只有新凭据、共享网络改动或新增生成测试等实质依赖缺少授权时才问；继续处理不受影响部分。
3. 配置 **先离线审阅，再备份、有限写入和验收**。容器路径固定镜像digest，本地uv路径固定源码ref/锁文件；均记录依赖版本和实际解释器，不用未经审查的latest或覆盖式更新。

## 关键约束

- 区分 Google 网页 Cookie 与网关 API key：前者只进入网关所在主机（NAS/服务器或Mac）的私密配置；GUI只得到网关key。默认让用户私下填写；跨客户端复用现有key也须有明确授权，不遍历其他账号/供应商，不自动提取浏览器凭据。
- 默认不发真实生成请求。先验证健康、鉴权、模型目录和客户端可见状态；若需要聊天/SSE验收，先核对范围与次数，使用无历史、无工具的最小标记提示，不把断线或失败当作重试授权。
- `/v1/models` 返回不等于账户可用性或网页完整模型清单。使用实际账户注册表证据；不硬编码他人的模型 ID、访客 ID、数量或套餐，也不静默回退模型。
- 上游宣布的工具、图片、推理参数等能力不等于当前镜像/适配层已实证。GUI默认不宣告未验证能力；WorkBuddy 的任务编排不等于 Gemini 网页原生 Task。
- 本地文件由客户端已声明且获准的工具读取/写入，模型和 NAS 不因收到路径就拥有本机磁盘。默认另存新文件；真实内容回传远端、覆盖、OCR、依赖安装与扩权限分别核对授权。
- 带工具流式缓冲、限定路径禁重试与有限队列必须一起按版本审查；等待首事件不等于挂死。排队时限不是 active 生成总时限，本机取消也不证明远端已取消；不自动重发。
- HTTP200、ACK、非空回复、`[DONE]`、产物或连接关闭分别证明不同层级；只报告观测。无产物不能证明远端没创建任务，本地退出不等于远端取消。
- Cookie、key、配置/备份、cache、HAR、原始认证响应、运行时 token、终端截图与聊天库均不作为公开附件。仅分享从零编写的模板、合成测试和经过审查的最小代码。

## 交付与完成条件

核对最终进程/容器/文件身份、所选模型真实ID、GUI可见状态、原有项保留和回滚点。区分“配置已保存”“只读连通”“聊天已验证”“原生任务未验证”，不要仅因进程退出码为0宣布全部完成。

文件工具另核接口调用/结果回传、客户端执行证据、实际新产物与原件保持；不能仅凭“已完成”或模型自述通过验收。文本完整性、插图与版面质量分开报告，不保证逐字或逐像素无损。

交付简短结果、验证范围及剩余限制。日志只保留固定错误码/状态/计数，不输出认证值；向外发布时显式列出文件白名单并检查实际 Git tree，而不只依赖 `.gitignore`。
